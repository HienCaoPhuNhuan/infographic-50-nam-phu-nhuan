# THPT Phú Nhuận - Infographic 50 năm

Infographic tĩnh 3 trang A4 về chủ đề “50 năm - những con số biết nói” của Trường THPT Phú Nhuận.

## Xem và in

- Mở `index.html` trong trình duyệt để xem.
- Chọn Print / Save as PDF.
- Thiết lập khổ giấy A4, Portrait, scale 100%, margin none hoặc default theo trình duyệt.
- CSS đã khai báo `@page` để xuất đúng 3 trang A4.

## Nội dung

Trang được tổ chức lại từ tài liệu DOCX:

- Trang 1: Lời mở đầu, các chỉ số tổng quan và mốc lịch sử 1976-2026.
- Trang 2: Thành tích nhà trường, học sinh, gương mặt tiêu biểu và học thuật.
- Trang 3: Đội ngũ giáo viên, câu lạc bộ, Đoàn thanh niên, văn hóa-thể thao và hoạt động cộng đồng.
